# Image Slots

Drop your real images here using these exact file names so they appear on the site.

| File name | Page | Description |
|-----------|------|-------------|
| about.jpg | Home | About preview image |
| team.jpg | About | Team / company photo |
| plumbing.jpg | Services | Plumbing service |
| electrical.jpg | Services | Electrical wiring service |
| hvac.jpg | Services | HVAC & ducting service |
| construction.jpg | Services | Construction service |
| project1.jpg ... project6.jpg | Projects | Project gallery images |

Replace a `<div class="img-placeholder">...</div>` block in the HTML with:

```html
<img src="assets/images/plumbing.jpg" alt="Plumbing work" />
```

The home page hero uses an animated SVG construction sequence (no image needed).
